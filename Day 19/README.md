# Day 19 - Instances, State, and Higher Order Functions

This folder contains my work for **Day 19** of the **100 Days of Python Bootcamp**.

## Project Overview

Day 19 focused on understanding how objects maintain their own state and how functions can be passed around as arguments.

To apply these concepts, I built two Turtle Graphics projects:

### Turtle Race

A game where multiple turtles race across the screen and the user places a bet on which turtle will win.

### Etch-A-Sketch

A drawing application controlled entirely by keyboard inputs, inspired by the classic Etch-A-Sketch toy.

## Topics Covered

- Object Instances
- State and Attributes
- Higher Order Functions
- Event Listeners
- Keyboard Controls
- Turtle Graphics
- User Interaction
- Event-Driven Programming

## Projects Included

### Turtle Race

The program:

- Creates multiple turtles with different colors
- Allows the user to place a bet
- Starts a random race
- Announces the winning turtle
- Displays whether the user's prediction was correct

#### Example

```text
Which turtle will win the race?
Enter a color: blue
The yellow turtle won the race!
You lost the bet.
```

### Etch-A-Sketch

A keyboard-controlled drawing application.

Controls:

- **W** → Move Forward
- **S** → Move Backward
- **A** → Rotate Left
- **D** → Rotate Right
- **C** → Clear Drawing and Reset Position

This project demonstrates event handling and user interaction through key presses.

## Personal Learning Notes

This day introduced me to a different style of programming called **event-driven programming**.

Some concepts that stood out were:

- Objects can maintain their own state independently.
- Functions can be passed as arguments without being called.
- Programs can react to user actions such as key presses.
- Event listeners make applications interactive and dynamic.

The Turtle Race project was particularly fun because it combined randomness with user interaction.

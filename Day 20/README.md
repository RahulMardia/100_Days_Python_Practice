# Day 20 & Day 21 - Snake Game

This folder contains my implementation of the **Snake Game**, built as part of **Day 20** and **Day 21** of the **100 Days of Python Bootcamp**.

## Project Overview

### Snake Game

In this project, I built the classic Snake game using Python's Turtle Graphics module and Object-Oriented Programming.

By the end of Part 2, the game includes:

- A moving snake made up of multiple segments
- Smooth snake movement
- Keyboard controls
- Randomly spawning food
- Snake growth after eating food
- Score tracking
- Collision detection with walls
- Collision detection with the snake's own body
- Automatic game over detection
- Modular, object-oriented code structure

## Topics Covered

- Object-Oriented Programming (OOP)
- Classes and Objects
- Working with Multiple Python Files
- Turtle Graphics
- Keyboard Event Listeners
- Screen Animation
- Collision Detection
- Game Loop
- Code Modularization

## Features

- Snake created using multiple turtle segments
- Continuous movement
- Arrow key controls
- Food spawning at random locations
- Snake grows after eating food
- Live score display
- Collision detection with walls
- Collision detection with the snake itself
- Smooth screen refresh using `screen.tracer()` and `screen.update()`
- Object-oriented implementation

## Personal Learning Notes

This project marked the beginning of building a complete graphical game in Python.

During **Part 1**, I focused on building the game's foundation by implementing the snake, movement, keyboard controls, and the game loop.

In **Part 2**, I expanded the project by adding food generation, score tracking, snake growth, and collision detection. These additions transformed the project into a fully playable Snake game.

This project significantly improved my understanding of:

- Object-Oriented Programming
- Separating responsibilities across classes
- Game loops and animation
- Collision detection

Building this game from scratch gave me a much deeper appreciation for how classic games are designed and structured.

# Day 20 - Snake Game (Part 1)

This folder contains my implementation of **Part 1** of the **Snake Game**, built as part of **Day 20** of the **100 Days of Python Bootcamp**.

## Project Overview

### Snake Game (Part 1)

In this part of the project, I built the foundation of the classic Snake game using Python's Turtle Graphics module and Object-Oriented Programming.

The game currently includes:

- A moving snake made up of multiple segments
- Smooth snake movement
- Keyboard controls
- Screen updates using animation
- Modular, object-oriented code structure

## Topics Covered

- Object-Oriented Programming (OOP)
- Classes and Objects
- Working with Multiple Python Files
- Turtle Graphics
- Keyboard Event Listeners
- Screen Animation
- Game Loop
- Code Modularization

## Features

- Snake created using multiple turtle segments
- Continuous movement
- Arrow key controls
- Smooth screen refresh using `screen.tracer()` and `screen.update()`
- Object-oriented implementation

## Controls

| Key | Action |
|-----|--------|
| ↑ | Move Up |
| ↓ | Move Down |
| ← | Move Left |
| → | Move Right |

## Personal Learning Notes

Day 20 marked the beginning of one of the largest projects in the bootcamp.

Instead of writing everything inside a single file, I learned how to organize the project into multiple classes, making the code cleaner, easier to understand, and easier to maintain.

Some concepts I practiced were:

- Creating objects from custom classes
- Managing the snake as a collection of segments
- Updating the screen efficiently
- Using keyboard events to control game movement
- Writing reusable and modular code

Building the snake movement from scratch gave me a much better understanding of how games update frame by frame.

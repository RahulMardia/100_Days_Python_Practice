# Day 18 - Turtle Graphics and GUI Programming

This folder contains my work for **Day 18** of the **100 Days of Python Bootcamp**.

## Project Overview

Day 18 focused on working with Python's built-in **Turtle Graphics** module and learning how to create visual drawings through code.

Throughout this day, I explored different drawing techniques, randomization, color manipulation, and geometric patterns.

## Topics Covered

- Turtle Graphics
- Importing Modules
- Aliasing Modules
- Working with External Packages
- RGB Color Mode
- Randomization
- Creating Shapes and Patterns
- GUI Programming Basics

## Projects Included

### Random Walk

A turtle graphics project where the turtle moves in random directions while drawing colorful paths, creating unique and unpredictable patterns.

### Spirograph

A program that draws a spirograph-style pattern by repeatedly drawing circles while rotating the turtle by a fixed angle.

### Hirst Painting

A recreation inspired by the artwork of :contentReference[oaicite:0]{index=0}, generated using Turtle Graphics.

The program:

- Uses RGB colors extracted from an image
- Draws a grid of colored dots
- Creates a digital version of a Hirst-style painting

# Day 21 - Introduction to Inheritance

This folder contains my work for **Day 21** of the **100 Days of Python Bootcamp**.

## Overview

Day 21 focused on one of the fundamental concepts of **Object-Oriented Programming (OOP)**: **Inheritance**.

Instead of building a complete project, this day was dedicated to understanding how one class can inherit properties and methods from another, allowing code to be reused and extended more efficiently.

## Topics Covered

- Inheritance
- Parent (Base) Classes
- Child (Derived) Classes
- Method Inheritance
- Extending Existing Classes
- Method Overriding
- Code Reusability
- Object-Oriented Design

## What I Learned

During this lesson, I learned how to:

- Create child classes from existing parent classes
- Reuse methods and attributes through inheritance
- Extend the functionality of existing classes
- Avoid code duplication
- Write cleaner and more maintainable object-oriented code

## Personal Learning Notes

Inheritance is a powerful feature of Object-Oriented Programming because it allows developers to build upon existing code rather than rewriting it.

Understanding inheritance helped me see how larger applications are structured, where specialized classes can inherit common behavior from more general classes while adding their own unique functionality.

Although this folder does not contain a complete project, it serves as an important milestone in learning advanced OOP concepts that will be used in future projects.
